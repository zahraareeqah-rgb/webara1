Fase 1: Pengenalan Konsep VPS & Cloud

  • Shared Hosting: Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna, sumber daya dibagi rata.
  • Dedicated Server: Server fisik utuh yang disewakan penuh untuk satu pengguna dengan kontrol dan performa penuh.
  • Amazon Lightsail: Layanan VPS instan dari AWS yang dikhususkan untuk pemula dengan konfigurasi sederhana dan harga tetap.
  • Amazon EC2: Layanan *Elastic Compute Cloud* dari AWS yang menyediakan virtual server (instance) fleksibel dan skalabel.

Fase 2: Persiapan dan Provisioning Server

  • [✔] Mengaktifkan akun AWS dan login ke Management Console[cite: 2].
  • [✔] Memilih Region AWS terdekat (misal: ap-southeast-1 / Singapore)[cite: 2].
  • [✔] Memilih Amazon Machine Image (AMI), misalnya Ubuntu 22.04 LTS / Windows Server[cite: 2].
  • [✔] Memilih Instance Type dalam batas Free Tier / Tipe yang sesuai[cite: 2].

  3. ls -la → A. Menampilkan seluruh file termasuk yang tersembunyi[cite: 3]
